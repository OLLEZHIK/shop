# Каталог инструментов (скиллы, плагины, MCP)

**Переносимый файл.** Как и `AGENTS.md`, этот документ не привязан к
конкретному проекту — его можно копировать целиком в другой репозиторий.
Здесь фиксируется то, что мы **нашли и оценили**, но необязательно уже
используем: что это, для чего годится, когда стоит ставить, как ставить.
Не документация по самим инструментам (за ней — по ссылке), а наша
заметка «зачем нам это и когда доставать».

## Как пользоваться этим файлом

- Нашли что-то полезное (скилл, плагин, MCP-сервер) — добавьте карточку
  сюда, даже если ещё не ставили. Решение о том, использовать ли и
  когда, отдельно от факта «мы это знаем и оценили».
- Статус `catalogued` → `evaluated` → `installed` — обновляйте по мере
  того, как решение о конкретном инструменте продвигается.
- Не копировать сюда документацию инструмента целиком — только вывод:
  зачем он нам, на каком этапе проекта пригодится, чего остерегаться.

## Дизайн / UI

### Impeccable
- **Тип:** плагин Claude Code (сторонний, не Anthropic).
- **Автор:** Paul Bakaus.
- **Что делает:** локальный детектор «AI slop» в UI-коде (61 паттерн
  типичных проблем ИИ-сгенерированного дизайна), git-интеграция для
  проверки PR, live-режим против запущенного приложения. Поддерживает
  `DESIGN.md`/`PRODUCT.md` для дизайн-системы проекта.
- **Установка:** `npx impeccable install` или
  `/plugin marketplace add pbakaus/impeccable` в Claude Code CLI.
- **Когда ставить:** когда в проекте появляется реальный UI-код,
  который пишет ИИ-агент — перед тем, как открывать PR с вёрсткой.
  Бессмысленно ставить раньше, пока UI-кода нет.
- **Статус:** `evaluated`, не установлен.

### emilkowalski/skills
- **Тип:** набор скиллов Claude Code (сторонний).
- **Автор:** Emil Kowalski (автор Sonner, Vaul).
- **Что делает:** 13 скиллов, в основном про анимацию/motion
  (`animate`, `improve-animations`, `review-animations`,
  `find-animation-opportunities`) плюс нативная мобильная разработка
  (`write-swift`, `mobile-native`, `apple-design` — не подходит для
  веб-проектов) и пара общих (`pick-ui-library`, `prototype`, `ask-sonner`).
- **Установка:** `npx skills@latest add emilkowalski/skills`.
- **Когда ставить:**
  - `pick-ui-library`, `prototype` — на этапе вёрстки базового макета.
  - `improve-animations`/`review-animations` — как полировочный проход
    **после** того, как базовая быстрая версия уже работает, не раньше
    (риск: анимации могут повредить Core Web Vitals, если увлечься).
  - Остальное (Swift/Expo/Apple HIG) — не релевантно для веб-проекта,
    не ставить.
- **Статус:** `evaluated`, не установлен.

### Anthropic «Design» (официальный плагин)
- **Тип:** плагин из официального маркетплейса Anthropic
  (`knowledge-work-plugins`).
- **Что делает:** критика дизайна, accessibility-аудит (WCAG),
  управление дизайн-системой, UX-копирайтинг, research synthesis,
  handoff в код. Интеграция с Figma, Slack, Notion и др.
- **Установка:** через каталог плагинов Claude Code (уже доступен без
  дополнительной настройки маркетплейса, в отличие от сторонних).
- **Когда ставить:** пересекается с Impeccable процентов на 70% —
  ставить один из двух, не оба сразу. Плюс перед Impeccable: доступен
  сразу, без `/plugin marketplace add`.
- **Статус:** `catalogued`, не оценён детально.

## Тестирование / автоматизация браузера

### Playwright MCP
- **Тип:** официальный MCP-сервер (Microsoft, пакет `@playwright/mcp`).
- **Что делает:** даёт агенту реальный браузер — открывать localhost,
  кликать, проверять вёрстку вживую, а не только по диффу кода.
- **Установка:** `claude mcp add playwright npx @playwright/mcp@latest`.
- **Когда ставить:** только там, где есть локальный доступ к
  запущенному приложению (Claude Code CLI локально, Antigravity) — у
  облачного Claude Code нет localhost, ставить туда бессмысленно.
- **Статус:** рекомендован для Claude Code CLI (локального), команда
  дана владельцу проекта.

## GitHub / репозиторий

### GitHub MCP (официальный, размещённый)
- **Тип:** официальный размещённый MCP-сервер GitHub.
- **Что делает:** PR, issues, ревью, комментарии — то же самое, что
  использует облачный Claude Code в этой сессии.
- **Установка:** `claude mcp add --transport http github https://api.githubcopilot.com/mcp/`
  (потребует OAuth-авторизацию в браузере при первом использовании).
- **Когда ставить:** сразу при подключении Claude Code CLI к проекту,
  если нужна работа с PR/issues напрямую, не только через `git`/`gh`.
- **Статус:** рекомендован для Claude Code CLI (локального).
