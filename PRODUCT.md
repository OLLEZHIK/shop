# PRODUCT.md

*Контекстный файл продукта — читается инструментами дизайн-ревью
(например, Impeccable) и людьми, кто впервые заходит в проект.
Источник истины подробнее — `docs/concept.md` и `docs/ux-flow.md`,
здесь только выжимка, которую ждёт формат PRODUCT.md.*

## Audience

Владелец собаки или кошки в Братиславе (Словакия), который ищет
конкретную услугу для питомца — грумер, ветклиника, отель/передержка,
зоомагазин, дрессировка — и не знает, где смотреть цены и кто
подходит. В основном заходит с телефона из Google по конкретному
запросу («груминг салон Братислава», «сколько стоит стрижка йорка»),
реже — напрямую на сайт зная его имя. Вторичная аудитория — владелец
самого салона/клиники, которому важно, чтобы данные о его бизнесе были
верными.

## Goals

- За 2-3 действия довести пользователя от запроса до конкретного
  контакта (позвонить / сайт / маршрут) — без регистрации, без форм.
- Быть источником, которому доверяют: у каждой цены и контакта —
  дата проверки и ссылка на источник, порядок в списках объяснён,
  платное размещение помечено отдельно и не смешано с обычным.
- Индексироваться и ранжироваться в Google по связкам
  «город + услуга + [порода]» — SEO не побочный эффект, а основная
  стратегия роста (программная генерация страниц по
  `docs/concept.md`, раздел 4).

## Platform

`adaptive` — сайт (не нативное приложение), mobile-first по
умолчанию, но должен полноценно работать и на десктопе. Стек:
Next.js (App Router) + TypeScript + Tailwind CSS, статическая
генерация с обновлением (подробнее — `docs/concept.md`, раздел 13).

## Constraints

- Без регистрации пользователей, без личного кабинета, без корзины/
  кошелька в MVP.
- Без рекламных блоков.
- Без cookie-трекеров без явного согласия; аналитика — без cookie
  (Plausible/Umami).
- Доступность: WCAG 2.1 AA — контраст, клавиатурная навигация, focus,
  alt, label, `lang="sk"`.
- Производительность: Core Web Vitals — цель LCP ≤ 2.5с на мобильном.
  Анимации и визуальные эффекты не должны идти в ущерб этой цели.
- Тексты интерфейса — на словацком языке, тон дружелюбный и простой.
- Никогда не выдумывать факты о бизнесах (адреса, цены, отзывы) — у
  каждого факта есть проверяемый источник или поле остаётся пустым.
- Страницы без достаточных реальных данных — `noindex`, не в sitemap.

## Terminology

- **Salon** — груминг-салон (стрижка, купание, тримминг).
- **Vet clinic** — ветеринарная клиника/амбулатория.
- **Pet hotel** — отель/передержка для животных.
- **District (mestská časť)** — один из 17 районов Братиславы (список
  в `docs/concept.md`, приложение B).
- **Partner** — помеченное платное размещение карточки; не
  смешивается с обычным порядком без явной пометки.
- **Overené (verified)** — статус данных с указанием даты последней
  проверки; данные старше 90 дней помечаются на переповерку.
- **Flow (3 шага)** — навигация с главной: тип животного → услуга →
  локация (подробнее — `docs/ux-flow.md`).

## Подтверждённые решения по бренду

- **Домен:** `pawenn.com` (куплен, DNS переключён на Cloudflare).
- **Референс интерфейса:** TripAdvisor-стиль (карточки, списки,
  browse-first) для результатов; десктопный поиск — комбинированная
  строка из трёх полей (вид животного / услуга / локация) по
  референсу Zocdoc, мобильный — карточки-шаги или вертикальный стек
  (см. `docs/ux-flow.md`).
- **Общий тон:** простой, дружелюбный, без маркетингового пафоса —
  сайт помогает выбрать, а не продаёт.
