# Задача: расширить список ветеринарных клиник Братиславы до полного

**Исполнитель:** Antigravity IDE
**Роль:** Data agent.
**Тип:** боевая задача (не тест), объём — максимально полное покрытие.
**Ветка:** `antigravity/data-vet-clinics-full-bratislava`

## Контекст

В `data/vet-clinics-bratislava.csv` уже есть 10 клиник, собранных в
пробном прогоне. Эта задача — не переделывать их, а **дополнить** файл
всеми остальными найденными ветеринарными клиниками Братиславы.

## Что сделать

1. Прочитать текущий `data/vet-clinics-bratislava.csv`, запомнить, какие
   клиники уже есть (по названию и адресу), чтобы не дублировать.
2. Найти максимально полный список ветеринарных клиник, реально
   работающих в Братиславе (включая районы), из публичных источников.
3. Дописать новые строки в конец того же файла (не создавать новый файл,
   не менять и не удалять уже существующие строки).

## Источники

- Сайты самих клиник, публичные каталоги (Zoznam.sk, Azet.sk и
  аналогичные), профессиональные ассоциации ветеринаров Словакии, если
  у них есть публичный реестр членов.
- Не использовать данные Google Maps / Google Places API как источник.
- Не копировать чужие отзывы.
- Не выдумывать ничего. Если поле не удалось найти — оставить пустым и
  написать причину в `notes`.

## Формат (не менять структуру файла)

```
name,address,district,phone,email,website,source_url,observed_at,notes
```

## Критерии готовности (Definition of Done)

- Существующие 10 строк не изменены и не удалены.
- Добавлены новые, реально уникальные клиники (не дубли уже имеющихся
  и не дубли друг друга) — без искусственного нижнего или верхнего
  порога по количеству: собери всё, что реально находится в открытых
  источниках, и остановись, когда новые источники перестают давать
  новые уникальные клиники (не изобретай клиники ради количества).
- У каждой новой строки заполнены минимум: `name`, `address` или
  `phone`, `source_url`, `observed_at`.
- В описании PR указать: сколько клиник было, сколько добавлено, какие
  источники использовались, и на чём поиск был остановлен (например,
  «проверены Zoznam.sk, Azet.sk и сайты клиник из выдачи по запросу
  X; новых клиник больше не находится»).
- Изменения закоммичены в ветку `antigravity/data-vet-clinics-full-bratislava`,
  запушены, открыт Pull Request в `main`.
