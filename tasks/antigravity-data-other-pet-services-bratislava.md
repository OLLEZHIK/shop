# Задача: собрать данные о прочих учреждениях для владельцев животных в Братиславе

**Исполнитель:** Antigravity (Desktop / Hub)
**Роль:** Data agent.
**Тип:** боевая задача (не тест), объём — максимально полное покрытие.
**Ветка:** `antigravity/data-other-pet-services-bratislava`

**Очерёдность:** выполнять после задачи
`antigravity-data-pet-hotels-bratislava.md` (сначала отели, потом это).
Если задача с отелями ещё не завершена (нет её ветки/PR) — сначала
доделать её, эту не начинать.

## Что сделать

Собрать данные о трёх категориях учреждений для владельцев собак/кошек
в Братиславе, которые ещё не покрыты другими файлами (не ветклиники, не
груминг-салоны, не отели для питомцев):

1. **Зоомагазины** (корм, аксессуары, ветеринарные аптеки при магазинах).
2. **Школы дрессировки / кинологические клубы**.
3. **Услуги выгула и передержки на дому** (pet-sitting, dog walking —
   именно разъездные/на дому услуги, не стационарные пансионы, это
   отдельная категория от отелей).

## Источники

- Сайты самих учреждений, публичные каталоги (Zoznam.sk, Azet.sk и
  аналогичные).
- Не использовать данные Google Maps / Google Places API как источник.
- Не копировать чужие отзывы.
- Не выдумывать ничего. Если поле не удалось найти — оставить пустым и
  написать причину в `notes`.

## Формат результата

Создать файл `data/other-pet-services-bratislava.csv` со столбцами:

```
name,category,address,district,phone,email,website,animals,source_url,observed_at,notes
```

- `category` — одно из: `shop`, `training`, `sitting` (по трём пунктам
  выше).

## Критерии готовности (Definition of Done)

- Собраны все реально найденные в открытых источниках варианты по
  каждой из трёх категорий, без искусственного порога по количеству.
- У каждой строки заполнены минимум: `name`, `category`, `address` или
  `phone`, `source_url`, `observed_at`.
- Нет дублей.
- В описании PR указать по каждой категории: сколько найдено, какие
  источники использовались, на чём поиск остановлен.
- Изменения закоммичены в ветку `antigravity/data-other-pet-services-bratislava`,
  запушены, открыт Pull Request в `main`.
