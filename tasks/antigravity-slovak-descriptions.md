# Задача: словацкие описания для всех 76 заведений

**Исполнитель:** Antigravity
**Роль:** Data agent.
**Тип:** сбор данных/контент, объём средний (76 записей, 4 CSV).
**Ветка:** `antigravity/slovak-descriptions`
**Зависимости:** нет (английские описания уже в `data/*.csv`, смёржено в PR #44).

## Контекст

Правило владельца (2026-09-23, `docs/design-plan.md` §2.2): всё, что
должно быть на местном языке, — на местном языке. У каждой страницы
есть словацкая версия (`/sk/...`), но описания заведений сейчас есть
только на английском (столбец `description`). На словацкой странице
заведения английский текст показывать нельзя: нет словацкого текста —
нет блока.

Почти все официальные сайты заведений и так на словацком, поэтому
основной источник — их собственный текст, а не перевод нашего
английского.

## Что сделать

В каждый из 4 файлов (`data/salons-bratislava.csv`,
`data/vet-clinics-bratislava.csv`, `data/pet-hotels-bratislava.csv`,
`data/other-pet-services-bratislava.csv`) добавить **в конец** один
столбец `description_sk` — 1-3 предложения на словацком.

1. Если на официальном сайте (столбец `website`) есть текст о себе —
   коротко пересказать его на естественном словацком для посетителя
   каталога. Без новых фактов, которых нет в источнике.
2. Если такого текста нет — перевести уже существующее английское
   `description` из той же строки на естественный словацкий (не
   дословно, но без добавления фактов).
3. Если пуст и `description` — оставить `description_sk` пустым.

По смыслу `description_sk` и `description` должны совпадать: одни и те
же факты, разные языки. Если при сверке с сайтом нашлась ошибка в
английском `description` — не править его молча, описать в PR.

## Правила

- Не выдумывать факты (адреса, годы, услуги, цены). Без превосходных
  степеней и рекламы («najlepší», «top»), если их нет в источнике — и
  даже если есть, лучше нейтрально.
- Нормальная словацкая грамматика и диакритика (ä, č, ď, ľ, ĺ, ň, ô,
  ŕ, š, ť, ž и т.д.), UTF-8.
- Существующие столбцы не трогать (ни порядок, ни значения) — только
  добавить новый в конец.

## Готово, когда

- Во всех 4 CSV есть столбец `description_sk`.
- Заполнен везде, где заполнен `description` (или в PR указано, почему
  нет).
- PR открыт в `main`, в описании: сколько записей взято с сайта
  заведения, сколько переведено с английского, сколько пустых.
