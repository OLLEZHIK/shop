# Задача: чего не хватает в Братиславе и что уже закрылось

**Исполнитель:** Antigravity
**Роль:** Research agent.
**Тип:** исследование, объём средний. **CSV не трогает**, поэтому идёт параллельно с задачами по данным.
**Ветка:** `antigravity/research-bratislava-coverage`
**Зависимости:** нет.

## Зачем

У прямого конкурента tippytaps.sk (см. `docs/research/competitors.md`)
только ветклиник 148 по Словакии, у нас в Братиславе — 76 заведений
всех категорий. Братислава — MVP-город: её покрытие должно быть не хуже,
чем у любого каталога. Параллельно в PR #57 всплыли заведения, которые,
возможно, закрыты (Zuzalo, EuroVet) — закрытое место в каталоге хуже,
чем отсутствующее.

## Что сделать

Создать `docs/research/coverage-bratislava.md` с двумя разделами.

### A. Кого у нас нет

Для 6 категорий (ветклиники, груминг, отели, дрессировка, зоомагазины,
присмотр) в Братиславе найти заведения, которых нет в `data/*.csv`.
Источники для **поиска кандидатов**: Google Maps, tippytaps.sk,
firmy.sk, zlatestranky.sk, Facebook, форумы.

Таблица по каждому кандидату:

| name | category | address | district | official website / соцсеть | где нашли | проверено: работает? (как проверили) |

- Каталоги (tippytaps и другие) — только чтобы узнать название.
  **Никаких данных оттуда не переносить** (адрес, телефон, текст, фото):
  всё — с официального сайта/страницы заведения или его карточки Google
  Maps. У баз данных в ЕС есть отдельная правовая защита, копировать
  чужой каталог нельзя.
- Кандидат без официального сайта/соцсети и без карточки Google Maps —
  не включать.
- `district` — slug района из наших данных (`petrzalka`, `ruzinov`, …).

### B. Кто из наших, возможно, закрыт

Пройти все 76 записей в `data/*.csv`: живой ли сайт, нет ли на Google
Maps пометки «Trvalo zatvorené», не переехали ли. Таблица только по
проблемным: | name | файл | что не так | где видно | дата проверки |.

## Правила

- Файл только в `docs/research/`, CSV и код не трогать. Добавление
  найденных заведений в данные — отдельная задача после ревью этого
  списка.
- Факты — только проверяемые, с источником.

## Готово, когда

- `docs/research/coverage-bratislava.md` с разделами A и B в PR.
- В описании PR: сколько кандидатов по каждой категории, сколько
  «возможно закрытых».
