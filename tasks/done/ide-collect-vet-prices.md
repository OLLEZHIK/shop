**Исполнитель:** Antigravity IDE
**Роль:** Data agent.
**Тип:** сбор нового среза данных, объём умеренный (34 ветклиники, цены будут не у всех).
**Ветка:** `antigravity/collect-vet-prices`
**Пауза (2026-09-25):** не брать. Сначала нужна прикидка, сколько клиник вообще публикует цены (скорее всего меньше трети), и решение владельца, стоит ли собирать. Приоритет сейчас — `ide-collect-logos-bratislava`.
**Зависимости:** нет. Задача **не трогает** существующие `data/*.csv`, а создаёт новый файл
`data/vet-prices-bratislava.csv`, поэтому идёт параллельно с очередью CSV-задач
(рейтинги → животные → часы работы → словацкие описания) и с `ide-review-insights`.

## Зачем

Прозрачные цены — основа продукта (`PRODUCT.md`, Goals). Для груминга
они уже есть (`data/salon-prices-bratislava.csv`), для ветклиник нет.
Запросы вроде «kastrácia mačky cena Bratislava» и «očkovanie psa cena»
частые, а конкурент (tippytaps.sk, см. `docs/research/competitors.md`)
показывает прайс прямо на карточке. Модель `PriceItem` в
`website/prisma/schema.prisma` уже готова и ждёт данных.

В прошлой задаче (`tasks/done/antigravity-collect-grooming-prices.md`)
ветклиники сознательно пропустили: «цены обычно по звонку». Но часть
клиник всё-таки публикует цены на сайте. Эта задача собирает то, что
опубликовано, и ничего больше.

## Что сделать

1. Для каждой из 34 клиник в `data/vet-clinics-bratislava.csv` открыть
   официальный сайт (колонка `website`) и найти опубликованный
   прайс-лист («Cenník», «Ceny», «Ceny služieb», PDF-прайс на том же
   сайте тоже подходит).
2. Создать `data/vet-prices-bratislava.csv` со столбцами:

   `clinic_name, service, species, weight_from_kg, weight_to_kg, price_from, price_to, currency, source_url, observed_at, notes`

   - `clinic_name` — **точно** как `name` в `data/vet-clinics-bratislava.csv` (по нему будет связка при сиде).
   - `service` — **только 6 кодов ветклиник из `docs/card-spec.md`, раздел «Цены»** (`exam`, `vaccination_dog`, `microchip`, `neuter_cat`, `spay_cat`, `spay_dog`). Решение владельца 2026-09-25: остальной прайс не собирать.
   - `species` — `dog`, `cat` или пусто (если цена общая для всех).
   - `weight_from_kg` / `weight_to_kg` — только если клиника сама делит цену по весу животного (частый случай для кастрации и наркоза): границы диапазона ровно как на сайте. «do 10 kg» — `weight_from_kg` пусто, `weight_to_kg=10`; «nad 40 kg» — `weight_from_kg=40`, `weight_to_kg` пусто. Не переводить в классы `MINI…XL`: единой таблицы «вес → класс» в проекте нет, а у клиник разные границы. Если цена от веса не зависит — оба поля пустые.
   - `price_from` / `price_to` — числа в EUR без символа валюты. Фиксированная цена — одно значение в обоих полях. «od 30 €» — `price_from=30`, `price_to` пусто.
   - `currency` — `EUR`.
   - `source_url` — прямая ссылка на страницу (или PDF) с ценой, не на главную.
   - `observed_at` — дата сбора (`YYYY-MM-DD`).
   - `notes` — **оригинальная строка прайса на словацком** как на сайте (как в `salon-prices-bratislava.csv`), плюс пояснение, если что-то неоднозначно.
3. Клиники без опубликованных цен («cena po dohode», «podľа rozsahu»,
   только телефон) — **не добавлять** в CSV, перечислить в PR.
4. Только эти 6 услуг. Если у услуги несколько весовых диапазонов —
   строка на каждый диапазон.

## Нельзя

- Выдумывать или «оценивать» цены.
- Брать цены из агрегаторов, соцсетей, форумов, Google-отзывов, чужих
  каталогов (включая tippytaps.sk). Только официальный сайт клиники.
- Править существующие `data/*.csv`, схему БД, `seed.ts`, сайт
  (`website/**`). Подключение к сайту — отдельная задача для CLI после мерджа.

## Definition of Done

- `data/vet-prices-bratislava.csv` создан, у каждой строки есть `source_url` и `observed_at`.
- Все `clinic_name` точно совпадают с `name` из `data/vet-clinics-bratislava.csv`.
- Все `service` — из 6 кодов ветклиник в `docs/card-spec.md`.
- CSV корректно парсится: запятые внутри `notes` в кавычках, кодировка UTF-8.
- В описании PR:
  - сколько клиник дали цены, сколько строк всего;
  - список клиник без опубликованных цен (одной строкой причина: «цены по звонку», «нет сайта», «сайт не открывается» и т.п.);
  - строки, в которых сомневаешься, отдельным списком.
- Ветка `antigravity/collect-vet-prices`, PR в `main`.

## Если что-то неясно

Не додумывать цены. Вопрос по конкретной позиции — в `notes` и в
разделе PR «сомнительные строки», остальное сдать. Вопрос, без ответа
на который нельзя двигаться, — в раздел `## Открытый вопрос` в PR,
и остановиться.
