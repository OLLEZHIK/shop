# Задача: координаты (lat/lng) для всех собранных записей

**Исполнитель:** Antigravity
**Роль:** Data agent.
**Тип:** обогащение уже собранных данных, объём умеренный.
**Ветка:** `antigravity/geocode-listings`

## Контекст

В Prisma-схеме (`website/prisma/schema.prisma`, поля `lat`/`lng` у
бизнеса) уже заложена возможность сортировки по расстоянию
(`docs/concept.md` раздел 8, «Сортировка... если пользователь
разрешил геолокацию»), но ни у одной из 76 собранных записей во всех
4 датасетах координат нет. Без них эта функция не может быть
включена. Подробнее про то, как это встраивается в страницы —
`docs/design-plan.md`, раздел 4.2.

## Файлы, которые нужно обработать

- `data/vet-clinics-bratislava.csv`
- `data/salons-bratislava.csv`
- `data/pet-hotels-bratislava.csv`
- `data/other-pet-services-bratislava.csv`

## Что сделать

1. Для каждой строки с определённым физическим адресом в Братиславе
   найти координаты (широта/долгота) — geocoding по адресу. Можно
   использовать публичный geocoding-сервис (например, Nominatim/
   OpenStreetMap) или сверку вручную по карте (mapy.cz,
   openstreetmap.org, google maps) — как удобнее и надёжнее.
2. Добавить в каждый файл две новые колонки: `lat`, `lng` (десятичные
   градусы, 5-6 знаков после запятой достаточно точности).
3. Для строк, где адрес выездной/без фиксированной точки (например,
   «Bratislava (výjazdové opatrovanie u klienta doma)» в
   `other-pet-services-bratislava.csv`) — оставить `lat`/`lng` пустыми,
   не придумывать условную точку в центре города. Это не ошибка, а
   ожидаемый случай — поясни в `notes`, если там ещё не написано,
   почему пусто.
4. Не трогать никакие другие колонки — только добавление `lat`/`lng`.
5. Один PR может затронуть все 4 файла — это одна связная задача, не
   нужно дробить на 4 отдельных PR.

## Критерии готовности (Definition of Done)

- У всех строк с определяемым физическим адресом заполнены `lat` и `lng`.
- Ни одной придуманной/приблизительной координаты без источника —
  geocoding по реальному адресу, не «примерно в этом районе».
- Выездные/без фиксированного адреса записи — `lat`/`lng` пустые, с пояснением в `notes`.
- Изменения закоммичены в ветку `antigravity/geocode-listings`, запушены, открыт Pull Request в `main`.
- В описании PR — сколько строк в каждом файле получили координаты, сколько остались пустыми и почему.
