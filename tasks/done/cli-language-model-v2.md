# Задача: языковая модель v2 — префикс у каждого языка, выбор языка на корне

**Исполнитель:** Claude Code CLI (локальный)

> **Сделано 2026-09-25 «левой рукой» (облачный Claude Code) по прямому указанию владельца**, ветка `claude/busy-volta-itqkmu`. x-default у внутренних страниц — английская версия (у главной — корень `/`); cookie `pawenn_lang` упомянуть в Privacy Policy — за владельцем.
**Роль:** Builder agent.
**Тип:** архитектура роутинга + фронтенд, объём средний.
**Ветка:** `cli/language-model-v2`
**Зависимости:** PR #48 (`claude/bold-rubin-7uapgz`, маршруты `app/[lang]`, словари, hreflang) смёржен в `main`.

CLI, потому что это архитектурное изменение, от которого зависят другие

## Контекст

Окончательное решение владельца — `docs/design-plan.md` §2.2, блок
«Языковая модель (владелец, 2026-09-23, окончательная)». Прочитать
целиком перед началом. Коротко: почти все ищут на местном языке,
поэтому всё про город — на языке города; у каждого языка свой префикс
(английский тоже); язык выбирается только на корне `/`.

PR #48 уже сделал: `app/[lang]`, `proxy.ts`, `lib/i18n.ts`
(`LOCALES`, `COUNTRY_LANGUAGE`, `localePath`), `lib/seo.ts`
(`localeAlternates`), `lib/localeSwitch.ts`, `LanguageSwitch`,
sitemap с alternates. Там английский живёт без префикса, а `/en/...`
редиректит на адрес без префикса. Эту часть нужно перевернуть.

## Что сделать

1. **Префикс у всех языков.** Английский — `/en/...`
   (`/en/grooming/bratislava/`, `/en/business/{slug}/`,
   `/en/how-it-works/`, юридические страницы и т.д.), словацкий как
   сейчас — `/sk/...`. `localePath`, `localeOfPath`, `switchLocalePath`
   и всё, что строит ссылки, — под новую схему.
2. **Старые адреса без префикса → 301 на `/en/...`** (все, что живы
   сейчас на `pawenn.com`: главная не считается — см. п. 3; категории,
   районы, `/business/{slug}/`, `/how-it-works/`, `/add-or-fix-listing/`,
   `/privacy-policy/`, `/terms-of-use/`). Неизвестные адреса — 404, не
   редирект.
3. **Корень `/` выбирает язык и редиректит** (временный редирект,
   307), порядок:
   1. cookie `pawenn_lang` (если значение — поддерживаемый язык);
   2. `Accept-Language` — первый поддерживаемый язык из списка;
   3. язык страны по `x-vercel-ip-country` через `COUNTRY_LANGUAGE`;
   4. `en`.

   Ответ корня с `Vary: Cookie, Accept-Language`. **Больше ни один
   адрес** не редиректит по cookie/браузеру/IP и не меняет текст —
   иначе ломается индексация (у ботов нет cookie).
4. **hreflang:** `x-default` — корень `/` (а не английская версия),
   остальное как в `localeAlternates`: self-canonical + все языковые
   версии страницы. Sitemap и `llms.txt` — под новые адреса.
5. **Cookie `pawenn_lang`:** пишется при клике в `LanguageSwitch`
   (1 год, `SameSite=Lax`, `Path=/`). Это функциональная cookie по
   явному выбору пользователя, баннер согласия для неё не нужен.
   Юридические тексты не трогать — в PR отдельной строкой указать, что
   cookie нужно упомянуть в Privacy Policy (добавит владелец).
6. **Внутренние ссылки держат язык посетителя.** Browse, геолокация
   «ближайший город», поиск, карточки — ведут на текущий язык
   страницы. Если у целевого города нет текущего языка (город в другой
   стране) — на язык этого города по умолчанию.
7. **Страна с несколькими языками:** `COUNTRY_LANGUAGE` → список
   языков (первый — по умолчанию), `localesForCountry` возвращает все
   плюс `en`. Сейчас реальных таких стран нет — просто чтобы схема не
   требовала переделки.
8. `PRODUCT.md` («Ворлд-вайд», «Constraints» — там сейчас «английский
   без префикса») привести в соответствие с `docs/design-plan.md`.

## Не делать

- Словацкие описания, Help/юридические на словацком, аудит строк —
  это `tasks/cli-full-local-language-sk.md` (следующая задача).
- Не менять словацкие слаги категорий — их задаёт
  `tasks/antigravity-slovak-keyword-research.md`.

## Готово, когда

- Все страницы открываются под `/en/...` и `/sk/...`; старые адреса без
  префикса отдают 301 на `/en/...`; корень `/` отдаёт 307 по порядку из
  п. 3 (проверить все 4 ветки, в т.ч. без cookie и без `Accept-Language`).
- canonical/hreflang/x-default проверены на каждом типе страниц; sitemap
  без адресов без префикса.
- Playwright (десктоп + 390px): переключатель EN/SK ведёт на ту же
  страницу и запоминается — после захода на `/` снова открывается
  выбранный язык; Browse и геолокация сохраняют язык.
- `npm run build` и `npm run lint` проходят.
- PR открыт в `main`.
