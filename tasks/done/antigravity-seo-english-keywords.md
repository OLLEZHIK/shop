# Задача: проверить английские URL-слаги и ключевые фразы

**Исполнитель:** Antigravity
**Роль:** Content/SEO research agent.
**Тип:** исследование, объём небольшой/умеренный.
**Ветка:** `antigravity/seo-english-keywords`

## Контекст

`docs/concept.md` (раздел 4, блок «Обновление после старта
разработки») явно предупреждает: при переходе на английский базовый
язык нельзя механически переводить словацкие URL-слаги — нужно
отдельное исследование английских ключевых слов, потому что объём
поиска на английском для Братиславы вероятно ниже словацкого и
структура запросов может отличаться. Чтобы не блокировать вёрстку
страниц, в `docs/design-plan.md` (раздел 3) я уже зафиксировал рабочую
схему URL:

```
grooming, vet-clinics, pet-hotels, pet-training, pet-shops, pet-sitting
```

Эта задача — проверить эту рабочую схему и, если нужно, предложить
замену с обоснованием, до того как страницы проиндексируются (сейчас
это дёшево поменять через 301, после индексации — дороже).

## Что сделать

1. Для каждой из 6 категорий (grooming/vet-clinics/pet-hotels/
   pet-training/pet-shops/pet-sitting) собери реальные примеры того,
   как на английском ищут аналогичные услуги в похожих (не
   обязательно словацких) городах — через обычный поиск в Google,
   автодополнение поиска, «люди также спрашивают», заголовки
   конкурентов (Rover.com, Yelp — уже частично разобраны в
   `docs/research/interface-references.md`, можно опираться на
   находки оттуда, не искать с нуля).
2. Для каждой категории зафиксируй:
   - Рекомендуемый URL-слаг (подтверди рабочий вариант или предложи альтернативу).
   - 2-3 реалистичные целевые фразы (title/H1/meta description кандидаты).
   - Честную оценку: есть ли вообще смысл ожидать заметный органический трафик по английским запросам именно для Братиславы (город небольшой, международного англоязычного спроса на локальные pet-услуги в Братиславе может физически не быть) — если оценка низкая, так и написать, не приукрашивать.
3. Не используй платные инструменты (Google Keyword Planner требует рекламный кабинет, Ahrefs/SEMrush платные) — если нет бесплатного доступа, обоснуй через доступные бесплатные сигналы (автодополнение, People Also Ask, заголовки живых конкурентных страниц), явно укажи в отчёте, что это не заменяет полноценный keyword research с объёмами, а является качественной, не количественной оценкой.
4. Результат — `docs/seo/english-keywords.md`, с таблицей (категория → рекомендуемый слаг → примеры фраз → краткое обоснование) и отдельным разделом с честной оценкой ожиданий по трафику.

## Критерии готовности (Definition of Done)

- `docs/seo/english-keywords.md` создан, по каждой из 6 категорий есть рекомендация и обоснование.
- Явно указано, где оценка качественная (не заменяет реальные данные по объёму поиска).
- Если предлагается изменить рабочий слаг из `docs/design-plan.md` — явно указано, что именно менять и почему.
- Изменения закоммичены в ветку `antigravity/seo-english-keywords`, запушены, открыт Pull Request в `main`.
