# Задача: цены Братиславы по новому правилу сравнимости

**Исполнитель:** Antigravity
**Роль:** Data agent.
**Тип:** сбор и проверка данных.
**Ветка:** `antigravity/prices-bratislava-v2`
**Зависимости:** нет (стандарт уже обновлён в `docs/card-spec.md`).

## Контекст

В `data/cities/bratislava/prices.csv` 97 цен для 20 заведений. Проверка
2026-09-25 показала: часть цен нельзя сравнивать между собой, потому что
заведения по-разному считают одну и ту же услугу (без наркоза, без
регистрации чипа, за час и т.п.). Сайт показывает цены рядом и
подсвечивает «дорого/дёшево», поэтому такие цены вводят в заблуждение.

Решение владельца: для каждой услуги стандарт фиксирует, **что входит в
цену**; части складываются; что сложить нельзя — помечается и не
сравнивается. Правило и новые колонки — `docs/card-spec.md`, раздел
«Цены», подраздел «Главное правило: одна услуга — одно содержание».
**Прочитать его перед началом.**

## Что сделать

Работать только в `data/cities/bratislava/prices.csv`.

### 1. Добавить новые колонки

В конец заголовка: `unit,partial,note,note_local` (см. `card-spec.md`,
«Файл и правила»). Существующие строки — пустые значения, пока не
исправлены по пунктам ниже.

### 2. Исправить известные проблемы

Всё ниже найдено при проверке; открыть `source_url` и проверить, что

### 3. Пройти все остальные строки

Каждую из 97 строк сверить с колонкой «Что считать» в `card-spec.md`:
- ветклиники: вакцинация — полная с бешенством; чип — с регистрацией;
  операции — с наркозом;
- груминг: цена всей процедуры, почасовая — с `unit=per_hour`;
- цена зависит от размера без веса — заполнен и `price_from`, и
  `price_to`.

Что исправил — одной строкой на заведение в описании PR.

### 4. Дособрать цены для категорий без цен

По правилам `card-spec.md` (коды, «что входит», только официальный сайт
или официальная соцсеть заведения):
- **отели для животных** (`PET_HOTEL`, 11 заведений);
- **дрессировка** (`DOG_TRAINING`, 7);
- **присмотр и выгул** (`PET_SITTING`, 4).

Список заведений — `data/cities/bratislava/businesses.csv`, колонка
`category`. Заведение не публикует цены — ни одной строки, в описании PR
так и написать.

## Чего не делать

- Не выдумывать цены и не брать их из каталогов, отзывов, «по телефону»
  (`AGENTS.md`).
- Не трогать `businesses.csv`, код сайта и файлы других городов.
- Не добавлять коды услуг, которых нет в `card-spec.md`.
- `note` / `note_local` — только короткие пометки для посетителя (до 40
  символов), не копия прайса. Строка прайса в оригинале — в `notes`.

## Критерии готовности

- В `prices.csv` заголовок с четырьмя новыми колонками, в каждой строке
  столько же значений, сколько в заголовке.
- Все проблемы из таблицы в п. 2 исправлены или в PR объяснено, почему
  нет (например, «цена наркоза на сайте не опубликована → partial»).
- У каждой строки с `partial=yes` заполнены `note` и `note_local`.
- В описании PR:
  - таблица: категория → сколько заведений всего / с ценами / сколько
    строк;
  - список исправлений по п. 2–3;
  - заведения отелей, дрессировки и присмотра без опубликованных цен.
- PR `Prices: Bratislava v2 (comparable prices)` в `main`.
