# Задача: собрать данные о 10 груминг-салонах для собак/кошек в Братиславе

**Исполнитель:** Antigravity (Desktop / Hub)
**Роль:** Data agent.
**Тип:** тестовая задача (проверка процесса), объём намеренно маленький.
**Ветка:** `antigravity/data-salons-bratislava`

## Что сделать

Найти 10 салонов груминга (стрижка, купание, тримминг) для собак и/или
кошек, работающих в Братиславе, и собрать по каждому базовые публичные
данные.

## Источники

- Только сайты самих салонов, публичные каталоги/справочники (например,
  Zoznam.sk, Azet.sk, Modrý psík, Salonprepsy.sk) и прайс-листы, которые
  сами салоны публикуют.
- Не использовать данные Google Maps / Google Places API как источник
  (искать через поиск можно, но не копировать структурированные данные
  из карт как есть — только то, что подтверждается сайтом самого салона).
- Не копировать чужие отзывы.
- Не выдумывать ничего. Если поле не удалось найти — оставить пустым и
  написать причину в `notes`.

## Формат результата

Создать файл `data/salons-bratislava.csv` со столбцами:

```
name,address,district,phone,email,website,animals,source_url,observed_at,notes
```

- `district` — район Братиславы, если удалось определить (см. список
  17 районов в `docs/concept.md`, если файл уже есть в репозитории;
  если файла нет — не изобретать район, оставить пустым).
- `animals` — через `;`, например `dog` или `dog;cat`.
- `source_url` — ссылка, откуда взяты данные по этой строке.
- `observed_at` — дата в формате `YYYY-MM-DD`, когда данные проверялись.
- Один салон = одна строка.

## Критерии готовности (Definition of Done)

- В файле ровно 10 строк с данными (не считая заголовка).
- У каждой строки заполнены минимум: `name`, `address` или `phone`,
  `source_url`, `observed_at`.
- Телефон и сайт салона по возможности проверены (страница открывается,
  номер выглядит правдоподобно для Словакии).
- Нет дублей (один и тот же салон дважды).
- Изменения закоммичены в ветку `antigravity/data-salons-bratislava`
  с понятным сообщением коммита.
- Открыт Pull Request в `main` с коротким описанием: сколько салонов
  собрано, откуда, что не удалось найти.
