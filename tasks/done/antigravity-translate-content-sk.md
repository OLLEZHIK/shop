# Задача: словацкие версии Help и юридических страниц

> **Закрыта 2026-09-26 («левая рука», по указанию владельца).** Отменена решением владельца (2026-09-25): Help и юридические страницы переводим по мере надобности, пока на `/sk/` ссылка на английскую версию с пометкой «(EN)». Юридические тексты ещё черновики до проверки юристом, переводить их сейчас рано.


**Исполнитель:** Antigravity
**Роль:** Content agent.
**Тип:** перевод/контент, объём небольшой (3 markdown-файла).
**Ветка:** `antigravity/translate-content-sk`
**Зависимости:** нет.

## Контекст

Правило владельца (2026-09-23, `docs/design-plan.md` §2.2): всё, что
должно быть на местном языке, — на местном языке. Сайт получает
словацкую версию (`/sk/...`), но Help и юридические страницы пока есть
только на английском — под `/sk/` они не открываются. Эта задача
готовит тексты; подключает их к сайту CLI
(`tasks/cli-full-local-language-sk.md`).

## Что сделать

Рядом с каждым исходником создать словацкую версию с суффиксом `.sk.md`:

| Исходник | Словацкая версия |
|---|---|
| `docs/content/how-it-works-draft.md` | `docs/content/how-it-works-draft.sk.md` |
| `docs/legal/privacy-policy-draft.md` | `docs/legal/privacy-policy-draft.sk.md` |
| `docs/legal/terms-of-use-draft.md` | `docs/legal/terms-of-use-draft.sk.md` |

1. Естественный словацкий, а не дословная калька. Структура (заголовки,
   списки, порядок разделов) — та же, что в исходнике, чтобы две версии
   было легко сверять.
2. **Плейсхолдеры `{OPERATOR}`, `{ADDRESS}`, `{EMAIL}` оставить как
   есть**, не подставлять никакие значения — их заполняет владелец
   (юридически значимое решение, `AGENTS.md`).
3. Юридические тексты: термины GDPR — в той форме, как они звучат в
   словацкой версии GDPR (Nariadenie (EÚ) 2016/679) и в
   zákon č. 18/2018 Z. z. (например «prevádzkovateľ», «dotknutá osoba»,
   «osobné údaje»). Первой строкой файла — пометка, что это черновик
   перевода, не проверенный юристом (как и английский исходник —
   черновик).
4. Ничего не добавлять и не убирать по смыслу. Если в исходнике
   что-то кажется ошибкой — перевести как есть и описать в PR.

## Готово, когда

- 3 файла `.sk.md` в PR, исходники не изменены.
- В описании PR — список мест, где перевод неоднозначен или исходник
  вызывает вопросы.
