# Задача: логотипы для всех заведений Братиславы

**Исполнитель:** Antigravity IDE
**Роль:** Data agent.
**Тип:** сбор данных, объём средний (49 заведений без логотипа).
**Статус (2026-09-25):** данные перенесены в `data/cities/bratislava/` облачным Claude Code (часы — из ветки, логотипы — из PR #73, кроме 7 непригодных). Остаток — в `tasks/antigravity-complete-bratislava-cards.md`.

**Ветка:** `antigravity/collect-logos-bratislava`
**Зависимости:** нет, брать сразу. **Приоритет выше, чем у
`ide-collect-vet-prices`** (та на паузе) **и `ide-review-insights`**.

## Зачем

Решение владельца (2026-09-25): у как можно большего числа карточек
должен быть логотип, а не инициалы. Сейчас логотип есть у **27 из 76**
заведений Братиславы, а у ветклиник — только у **5 из 34**. Раньше
логотип искали в основном на сайте. Теперь правила шире: аватары
официальных страниц в Facebook и Instagram тоже подходят.

Цель — **логотип у ≥ 60 из 76** (≈ 80 %).

## Что сделать

1. Взять все записи из `data/salons-bratislava.csv`,
   `data/vet-clinics-bratislava.csv`, `data/pet-hotels-bratislava.csv`,
   `data/other-pet-services-bratislava.csv`, у которых `logo_file` пустой.
2. Для каждой искать логотип **строго по порядку источников и правилам
   из `docs/playbooks/add-city.md`, раздел 5**: шапка сайта → иконки
   сайта → `og:image` → аватар Facebook → аватар Instagram → логотип
   бренда сети.
3. Сохранить файл в `website/public/logos/<slug>.png|svg|webp`, где
   `<slug>` — slug заведения на сайте (`/business/<slug>/`); так же
   названы уже существующие файлы в этой папке.
4. Записать результат в **новый файл** `data/logos-bratislava.csv`:

   ```
   name,logo_file,logo_source,logo_source_url
   ```

   - `name` — точно как `name` в исходном CSV;
   - `logo_file` — имя файла (`vetline-veterinarna-nemocnica.png`) или
     пусто, если логотипа нет нигде;
   - `logo_source` — `site-header`, `site-icon`, `og-image`,
     `facebook-avatar`, `instagram-avatar`, `chain-brand` или `none`;
   - `logo_source_url` — страница, откуда взят логотип. Для `none` —
     где смотрели, через `;`.

   **Сами `data/*-bratislava.csv` в этой задаче не трогать.** Их сейчас
   правит Antigravity Mac (`mac-collect-hours-and-vet-services`). Если
   менять те же строки параллельно, будут конфликты. Перенос
   `logo_file` в основные CSV — шаг 5.
5. **После того как PR Mac по часам работы смёржен** (проверить на
   GitHub): в той же ветке подтянуть свежий `main` (`git merge
   origin/main`) и перенести `logo_file` из `data/logos-bratislava.csv`
   в столбец `logo_file` основных CSV скриптом (сопоставление по
   `name`). Дописать в `notes` каждой такой строки
   `logo: <logo_source>`. Если PR Mac к этому моменту ещё не смёржен —
   открыть PR без шага 5 и написать об этом в описании. Шаг 5 тогда
   сделает оркестратор или ты отдельным коммитом позже.

## Нельзя

- Картинки из Google Maps / Google Business Profile, каталогов и
  агрегаторов.
- Рисовать, генерировать или вырезать логотип из фото.
- Аватар, на котором фото (собака, люди, помещение), а не логотип.
- Заменять 27 уже существующих логотипов. Исключение: файл явно
  битый или меньше 128 px. Такие перечислить в PR.

## Definition of Done

- `data/logos-bratislava.csv`: строка на каждое заведение, у которого
  не было логотипа (49 строк).
- Каждый `logo_file` из этого CSV существует в `website/public/logos/`,
  ≥ 128 px по короткой стороне (аватар 150 px — нормально), ≤ 100 КБ.
- В PR:
  - было 27 / стало N логотипов из 76, отдельно по ветклиникам;
  - сколько из каких источников (`site-header`, `facebook-avatar`, …);
  - список `none` с тем, где смотрели;
  - сделан ли шаг 5.
