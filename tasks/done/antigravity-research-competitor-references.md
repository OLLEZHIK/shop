# Задача: углублённый ресёрч референсов интерфейса

**Исполнитель:** Antigravity (IDE или Desktop/Hub — любой свободный)
**Роль:** research, не код.
**Тип:** подготовка к вёрстке, не блокирует Claude Code CLI.
**Ветка:** `antigravity/research-competitor-references`

## Контекст

`docs/ux-flow.md` уже опирается на паттерны Zocdoc (комбинированная
строка поиска) и общую практику TripAdvisor-style директорий. Перед
тем как Claude Code CLI дойдёт до вёрстки (Sprint 0, T0.3 из
`docs/concept.md`), полезно иметь более конкретные, насмотренные
референсы — не общие описания, а разбор реальных экранов.

## Что сделать

Разобрать вживую (по возможности со скриншотами, если инструмент это
позволяет, иначе — подробным текстовым описанием) минимум **3
сайта-аналога** из списка ниже (или похожих, если это окажется удобнее):

1. **Zocdoc** (zocdoc.com) — десктоп и мобильная версия отдельно.
2. **Rover** (rover.com) — маркетплейс услуг для собак, похожая
   вертикаль (передержка/выгул).
3. **Yelp** (местная категория услуг, например «pet groomer») —
   классический пример карточек списка + фильтров.
4. По желанию — любой словацкий/чешский аналог (Modrý psík,
   Salonprepsy.sk и т.п. уже упомянуты в `docs/concept.md`, но их
   интерфейс отдельно не разбирался).

По каждому сайту зафиксировать:
- Как устроена карточка результата (что на ней, в каком порядке).
- Как работают фильтры (сколько их, где расположены, сворачиваются ли).
- Как выглядит переход от списка к детальной странице.
- Что по мобильной версии — совпадает ли раскладка с десктопом или
  принципиально другая (карточки, свайпы, sticky-элементы).
- Субъективная оценка: что заимствовать, что не подходит под нашу
  специфику (без бронирования, без личного кабинета — см. `PRODUCT.md`).

## Формат результата

Файл `docs/research/interface-references.md` — по одному разделу на
сайт, с выводами. В конце — короткий раздел «Рекомендации для нашего
макета» со ссылками на конкретные пункты `docs/ux-flow.md`, которые
это подтверждает или заставляет пересмотреть.

## Критерии готовности (Definition of Done)

- Минимум 3 сайта разобраны по всем пунктам выше.
- Файл создан по указанному пути, не трогает никакие другие файлы
  (особенно не трогает код приложения — этим параллельно занимается
  Claude Code CLI).
- Закоммичено в ветку `antigravity/research-competitor-references`,
  запушено, открыт Pull Request в `main`.
