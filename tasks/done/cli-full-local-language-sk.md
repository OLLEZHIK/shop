## Контекст

Решение владельца — `docs/design-plan.md` §2.2, блок «Языковая модель
(владелец, 2026-09-23, окончательная)», пункты 2 и 7. Всё про город — на
языке города. На `/sk/...` не должно остаться видимого английского
текста там, где он может быть словацким: нет словацкого текста — нет
блока, английский вместо него не подставляется. На `/en/...` —
английский текст, если он есть, иначе местный. Названия заведений и
адреса не переводятся.

## Что сделать

1. **Описания по языкам.**
   - Схема: `Business.descriptionI18n Json?` — объект `{ "<locale>": "текст" }`
     (сейчас только `sk`). `Business.description` остаётся английским.
     Миграция против реальной БД (`prisma migrate`), как в
     `cli-integrate-descriptions-and-photos`.
   - `prisma/seed.ts`: читать **все** столбцы вида `description_<locale>`
     из CSV обобщённо (не хардкодить `description_sk`) — новый язык
     должен добавляться только новым столбцом CSV. Пустые значения не
     писать.
   - Рендер (карточка списка и страница заведения): на странице
     местного языка `L` — только `descriptionI18n[L]`, нет текста — нет
     блока (английский не подставлять). На `/en/...` — `description`,
     а если его нет — текст на языке города по умолчанию.
   - Прогнать сид против реальной БД, в PR — число заведений с
     непустым словацким описанием.
2. **Help и юридические страницы на `/sk/`** (сейчас 404): подключить
   `docs/content/how-it-works-draft.sk.md`,
   `docs/legal/privacy-policy-draft.sk.md`,
   `docs/legal/terms-of-use-draft.sk.md`. Словацкие слаги страниц —
   на усмотрение исполнителя (без диакритики), с hreflang к английским
   версиям. Юридические остаются `noindex`, как английские. Убрать
   пометку «(EN)» в футере на `/sk/`.
3. **Аудит всех видимых строк на `/sk/`.** Пройти все типы страниц
   (главная, категория, категория+район, заведение, Help, юридические,
   404, пустое состояние фильтров) и всё, что видит пользователь или
   поисковик: тексты интерфейса, FAQ и их JSON-LD, meta title/description,
   OpenGraph, `alt` у картинок, `aria-label`, тексты ошибок формы
   отзыва (включая сообщения от `/api/reviews`), даты, форматы цен.
   Всё английское — перевести через словари `lib/i18n.ts`. Если
   какая-то строка идёт из данных, а словацкой версии данных нет —
   описать в PR, не переводить данные «на глаз».
4. **Не делать:** выбор языка, cookie, редиректы и префиксы — это уже
   сделано в `tasks/cli-language-model-v2.md`, не переделывать.

## Готово, когда

- Миграция применена к реальной БД, сид прогнан, число словацких
  описаний указано в PR.
- Help и юридические страницы открываются на `/sk/` на словацком, с
  hreflang.
- Проверено Playwright на всех типах страниц `/sk/` (десктоп + 390px):
  видимого английского текста нет, кроме названий/адресов заведений и
  того, что явно перечислено в PR с причиной.
- `npm run build` и `npm run lint` проходят.
- PR открыт в `main`.
