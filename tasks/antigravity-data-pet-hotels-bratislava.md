# Задача: собрать данные об отелях/передержке для питомцев в Братиславе

**Исполнитель:** Antigravity (Desktop / Hub)
**Роль:** Data agent.
**Тип:** боевая задача (не тест), объём — максимально полное покрытие.
**Ветка:** `antigravity/data-pet-hotels-bratislava`

## Что сделать

Найти все реально работающие в Братиславе места, где можно оставить
собаку или кошку на передержку/проживание на время отсутствия хозяина:
пансионы для животных («penzión pre psov/mačky»), гостиницы для
животных, передержка на базе питомников.

Это отдельная категория от груминг-салонов (`data/salons-bratislava.csv`)
и от ветклиник — не путать и не смешивать в один файл.

## Источники

- Сайты самих пансионов/гостиниц, публичные каталоги (Zoznam.sk,
  Azet.sk и аналогичные).
- Не использовать данные Google Maps / Google Places API как источник.
- Не копировать чужие отзывы.
- Не выдумывать ничего. Если поле не удалось найти — оставить пустым и
  написать причину в `notes`.

## Формат результата

Создать файл `data/pet-hotels-bratislava.csv` со столбцами:

```
name,address,district,phone,email,website,animals,source_url,observed_at,notes
```

- `animals` — через `;`, например `dog` или `dog;cat`.

## Критерии готовности (Definition of Done)

- Собраны все реально найденные в открытых источниках варианты, без
  искусственного порога по количеству — не изобретать записи ради
  плана, но и не останавливаться после первых 2-3, если реально есть
  больше.
- У каждой строки заполнены минимум: `name`, `address` или `phone`,
  `source_url`, `observed_at`.
- Нет дублей.
- В описании PR указать: сколько мест найдено, какие источники
  использовались, на чём поиск остановлен.
- Изменения закоммичены в ветку `antigravity/data-pet-hotels-bratislava`,
  запушены, открыт Pull Request в `main`.
