# Конкуренты

## tippytaps.sk (найден владельцем 2026-09-24)

Каталог ветеринарии, груминга, зоогостиниц и дрессировки по всей
Словакии. Без бронирования: сравнить, позвонить, приехать. Разобрано
облачным Claude Code 2026-09-24 по публичным страницам.

**Масштаб и модель**
- 287 «overených miest» по ~10 городам, из них 148 ветклиник.
- Языки: словацкий + отдельный домен tippytaps.cz. **Английского нет.**
- Для бизнеса всё бесплатно («0 €», «žiadne mesačné poplatky»):
  профиль, фото, цены, бейдж «Overená prevádzka», статистика просмотров.
  Платных тарифов пока нет — набирают базу.
- WordPress, свои типы записей (`tt_clinics`, `tt_salon_city` …),
  «Est. 2026». Та же команда — TopLekári.sk (каталог врачей).
- Город выбирается параметром (`/kliniky/?mesto=bratislava`), отдельные
  страницы город × услуга — в sitemap (`tt_vet_city`, `tt_salon_city` …).

**Сильные стороны (чего нет у нас)**
- Фильтры ветклиник: «Otvorené teraz», «Pohotovosť 24/7» (отдельная
  страница `/kliniky/pohotovost/`), выходные, выезд домой, экзоты
  (рептилии, птицы, лошади), специализации. → задача
  `tasks/mac-collect-hours-and-vet-services.md`.
- На карточке: часы работы, прайс, услуги, логотип.
- Логотип почти у всех (13–15 из 15 на выборочных страницах). Как
  сделано:
  1. Берут настоящий логотип с сайта/соцсети клиники (сверено:
     CeziVET, LapVet, Super zoo, Nemček, Dúbrava — оригинальные), вместе
     со словесной частью, а не только значок.
  2. **Нормализуют всё в одинаковый квадрат** 1254×1254 px на белом фоне
     с полями — поэтому сетка выглядит однородно, даже когда исходник
     широкий.
  3. Где графического логотипа нет — **набирают название текстом** в
     квадрате (пример: «VETERINÁR ŠVIHRAN»), изредка ставят фото.
  У нас пункт 2 решается вёрсткой (любой логотип в квадратной белой
  плашке с полями, `object-contain`), пункт 3 — уже есть (инициалы).
  Разница в покрытии — в пункте 1: мы брали только достаточно чёткие
  логотипы с сайтов, соцсети почти не использовали.

**Слабые стороны / чего не делать**
- Показывают 5 отзывов из Google **дословно, с именами авторов** —
  против условий Google. У нас правило: отзывы не копировать.
- Нет английской версии — экспаты в Братиславе не обслужены.
- Одна страна на домен; у нас «город + его язык» на одном домене.

**Правило для наших агентов:** их тексты, фото, отзывы и данные не
копировать (в ЕС у баз данных отдельная правовая защита). Использовать
только как список названий для поиска и как ориентир по функциям.

**Что отслеживать** (раз в месяц): платные тарифы, английская версия,
новые города, число мест.
