# Как добавить язык сайта

Новый город на уже поддерживаемом языке — это только данные
(`docs/architecture/multi-city.md`). Новый **язык** — разовая работа с
кодом, после неё все города на этом языке снова добавляются только
данными. Пример ниже — немецкий (`de`) для Вены.

**Кто делает:**
- Перевод интерфейса (файл словаря) и исследование запросов для слагов
  категорий — Antigravity. Это текст, а не вёрстка.
- Подключение языка в коде и визуальная проверка — Claude Code CLI или
  «правая рука» (правило про фронтенд в `AGENTS.md`).

## 1. Что поменять в коде

TypeScript сам показывает, что ещё не переведено: после шага 1 `npx tsc
--noEmit` выдаёт ошибку в каждом месте, где не хватает нового языка.

1. **`website/lib/locales.ts`:**
   - `LOCALES` — добавить `"de"`;
   - `DATE_LOCALE` — добавить `de: "de-AT"` (или `de-DE`): формат дат
     и правила множественного числа.

   Префикс `/de/` в `proxy.ts` и страница 404 подхватят язык сами.
2. **`website/lib/dictionaries/de.ts`** — скопировать `en.ts` и
   перевести все строки. Тип `Dictionary` не даст пропустить ключ.
   Подключить в `website/lib/i18n.ts` (`DICTIONARIES`).
   - Строки-функции (`(count, where) => …`) переводить целиком, с
     правильными формами слов. Для чисел использовать `plural("de", n,
     {one, other})`: правила языка берутся из `Intl.PluralRules`, для
     чешского и польского есть ещё формы `few` и `many`.
   - «В городе» не собирать в словаре: оно приходит из `in_city` в
     `city.json`.
3. **`website/lib/categories.ts`:**
   - `SLUGS` — адреса категорий на новом языке (по исследованию
     запросов, как `docs/seo/english-keywords.md`). **Слаг — это
     адрес: после запуска его не менять.**
   - `LABELS`, `SINGULAR`, `PLURAL`, `SEO_TITLE`, `BLURBS` — названия.
   - `BUSINESS_SEGMENT` (`podnik` → `betrieb`), `CITY_SEGMENT`
     (`mesto` → `stadt`).
4. **`website/lib/services.ts`** и **`website/lib/vet.ts`** —
   подписи цен и специализаций ветклиник.
5. **`website/components/LanguageSwitch.tsx`** — `NAMES`, название
   языка на нём самом (`Deutsch`).

Страницы помощи и юридические тексты остаются на английском и
помечаются «(EN)», пока их не переведут отдельно. Юридические тексты
переводит только владелец.

## 2. Что поменять в данных

- В `city.json` каждого города на этом языке указать `"locales":
  ["de"]` и `"in_city": {"en": "in Vienna", "de": "in Wien"}`.
- Тексты заведений на местном языке (`*_local` в `businesses.csv`,
  `docs/card-spec.md`) собираются на языке города, как и сейчас.

## 3. Проверка перед PR

- `npx tsc --noEmit` и `npx eslint` без ошибок.
- На тестовой базе с городом на новом языке (`website/prisma/fixtures/`):
  - `/de/`, `/de/stadt/<город>/` и страница категории отдают 200;
  - hreflang связывает `de` с английской версией;
  - в `sitemap.xml` есть страницы `/de/`;
  - для города без `de` в `locales` страница `/de/...` отдаёт 404.
- Скриншоты главной, хаба города, списка и карточки на телефоне:
  длинные немецкие слова не ломают вёрстку.
- В `docs/seo/README.md` §2.1 дописать слаги нового языка.
