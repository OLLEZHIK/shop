# Прототип «Zocdoc × pawenn»

Кликабельный прототип направления, которое выбрал владелец (2026-09-26):
структура и приёмы Zocdoc, цвета pawenn (оранжевый `#FF6B35` для
главного действия с тёмным текстом, синий `#004E89` для ссылок, тёмно-синий
`#0B2545` для заголовков), шрифт DM Sans. Код сайта не меняет — это
образец для редизайна.

- `index.html` — вся страница (без `<html>/<head>`, их добавляет Artifact).
- `data.json` — 76 мест, 145 цен, 17 районов из локальной базы с сидом
  на 25. 9. 2026; рынок цен и уровни € посчитаны по правилам
  `website/lib/priceMarket.ts`.
- `build_data.py` + `export.sql` — как `data.json` собран
  (`psql -f export.sql` → `raw.json` → `python3 build_data.py`).
- Логотипы берутся из `website/public/logos/bratislava/` (в прототипе
  лежат рядом в папке `logos/`).

Что работает: главная (поиск по услуге и району, «Práve teraz» со
счётчиком открытых сейчас, услуги, цены, районы), списки категорий и
районов, страницы-признаки ветеринаров, фильтры (открыто сейчас,
животное, рейтинг, район, сортировка), поиск по названию/району/услуге,
меню, карточка места (часы неделей, цены с рынком, сводка отзывов, FAQ,
контакты, похожие), страницы цен, город, «Pridať záznam», 404.
«Открыто сейчас» считается по часам Братиславы в момент просмотра.
Кнопка «Zavolať» в прототипе не звонит, а показывает номер.
